Enforce Granular Code Reviews

Ensure the right people approve your code by creating custom reviewer groups with specific approval minimums.

Requires Bitbucket Premium

Getting Started

Follow these steps to configure your repository gates:

1

Create Groups

Open the app in your repository settings. Use the "Create New Group" section to define groups like "Architecture," "QA," or "Security."

2

Set Minimums

For each group, define exactly how many approvals are required. For example, you might require 2 approvals from "Senior Devs" and 1 from "DevOps."

3

Assign Users

Search through your workspace members or default reviewers and assign them to their respective groups via the dropdown menus.

How it works: When a user attempts to merge a Pull Request, our custom merge check scans the current approvers. If any group hasn't met its minimum requirement, the merge is blocked until the right people sign off.

Privacy & Data Security

Your security is our priority. This application is built on Atlassian Forge, meaning your data stays within the Atlassian ecosystem.

"We store Bitbucket Account IDs and group configurations within Atlassian's Forge Storage. No data is transmitted to or stored on external servers."

  • Data Localization: All configuration data is stored in Atlassian's secure Forge Storage.
  • No External API calls: The app does not communicate with any third-party analytics or tracking services.
  • Identity: We only reference Atlassian Account IDs to verify group membership during the merge process.
